# charlesponeill.com

Personal website built with Jekyll, deployed via GitHub Pages from `main`.

## Structure

- `index.html`, `posts/index.html`, `research.html`: home, writing and papers pages.
- `_posts/`: essays. Front matter: `title`, `date`, `description` (the italic deck line), `tag` (`ai` or `other`), optional `math: true` and `hidden: true`. Section headings inside a post are `#` (they build the contents list) and subsections `##`. Footnotes (`[^1]`) render as margin notes on wide screens.
- `_data/papers.yml`, `_data/notes.yml`: papers and Baseten Research notes; `selected: true` puts a paper on the home page.
- `assets/css/style.scss`, `_sass/`: styles and tokens. EB Garamond is self-hosted from `assets/fonts/`.
- `feed.xml` is generated by `jekyll-feed`.

## Local Development

**Prerequisites:** Homebrew Ruby (macOS system Ruby is too old)

```bash
brew install ruby
echo 'export PATH="/opt/homebrew/opt/ruby/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc
```

**Run locally:**

```bash
bundle install    # first time only
bundle exec jekyll serve --livereload
```

Site will be at http://127.0.0.1:4000 with auto-refresh on save.
