# charlesponeill.com

Personal website built with Jekyll, deployed via GitHub Pages from `main`.

## Structure

- `index.html`, `posts/index.html`, `research.html`: home, writing and papers pages.
- `_posts/`: essays. Front matter: `title`, `date`, `description` (the italic deck line), `tag` (`ai` or `other`), optional `math: true`, `hidden: true` and `shelf: true`. Section headings inside a post are `#` (they build the contents list) and subsections `##`. Footnotes (`[^1]`) render as margin notes on wide screens.
- `_data/papers.yml`, `_data/notes.yml`: papers and Base Labs / Baseten Research notes; `selected: true` puts a paper on the home page.
- `assets/css/style.scss`, `_sass/`: styles and tokens. EB Garamond is self-hosted from `assets/fonts/`.
- `assets/js/paint.js`: the shared watercolour library (washes, brushstrokes, boats, moths, ferns), all painted procedurally on canvas with no image assets. The paper colour, grain and the one red (`--rubric`) live in `_sass/_variables.scss`.
- `assets/js/sails.js`: the boats on the home page. They sail the margins at ≥1180px and a strip above the portrait below that.
- `assets/js/marginalia.js`: the small things on every page. In essays: a rubricated initial on a wash, acronyms in small caps, a boat for each `---` section break, a hedera after the last word, a wash behind the phrase a footnote belongs to, a reader's pencil (press and hold a sentence; marks stay in that reader's browser) and foxing on essays more than two years old (the paper itself warms via `--age`, set in the post layout). Elsewhere: a moth that comes to a link you rest on at night, the envelope on the home page, the shelf on reading lists and the 404 library card.
- Reading lists (`shelf: true` in front matter) draw their list as spines under a bookplate. `_data/books.yml` sets each book's spine thickness; add `mum: true` to pencil an m on anything Mum recommended.
- Figures in ink and wash are a `<canvas>` in the post plus a small script that draws with `window.Paint`; see `assets/js/kv-cache-figure.js`. An essay's opening image gets a deckled edge, as does any image given `{: .deckle}`.
- `feed.xml` is generated by `jekyll-feed`.

## Local Development

**Prerequisites:** Homebrew Ruby (macOS system Ruby is too old)

```bash
brew install ruby
echo 'export PATH="/opt/homebrew/opt/ruby/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc
```

**Run locally:**

```bash
bundle install    # first time only
bundle exec jekyll serve --livereload
```

Site will be at http://127.0.0.1:4000 with auto-refresh on save.
